# ISM B Hostel - Abu Dhabi (ISMB)

A modern, responsive web application for **ISM B Hostel** in Al Mushrif, Abu Dhabi. Built with React, Vite, TypeScript, and Tailwind CSS.

## 🏨 Features
- **Hero & Interactive Presentation**: High-resolution imagery of the boutique hostel, majlis lounge, and Abu Dhabi landmarks.
- **Dorm & Private Room Catalog**: Multi-currency pricing (AED, USD, EUR, INR), amenities listing, and instant booking modal.
- **Bilingual Experience**: Full English & Arabic (RTL) interface with font optimization (`Cairo`, `Tajawal`, `Cinzel`, `Plus Jakarta Sans`).
- **User Bookings Dashboard**: Local reservation management, print-ready receipt generator, and pre-arrival guide.
- **Interactive Landmark Map & Reviews**: Proximity indicators to Vietnam Embassy, Sheikh Zayed Grand Mosque, and Al Mushrif Park.
- **Vercel & SPA Optimized**: Includes pre-configured `vercel.json` for routing rewrites and zero-404 asset caching.

## 🚀 Getting Started

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

## 🌐 Deploying to Vercel
1. Push this project to your GitHub repository.
2. Import the repository into [Vercel](https://vercel.com).
3. Framework: **Vite** (auto-detected).
4. Output Directory: `dist`.
5. Click **Deploy**.
